# 收紧 UI 说明文本 Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 去掉界面上重复解释控件自己已经说清的话，只留下「误解会静默出错」的一句。

**Architecture:** 不改交互结构、不加 tooltip 系统、不抽 `copy.ts`。SchemaForm 继续渲染 `schema.description`；变短的办法是删掉/改写 description 本身。`sql.query` / `http.request` / `notify.wecom` / `postgres.workspace` 的展示文案必须前后端各改一份（`applyBackendNodes` 整份覆盖，前端多写的说明上线即消失）。Inspector 里按 `typeId === 'http.request'` 写的重试说明是特判，直接删掉。

**Tech Stack:** `src/registry.ts` + `server/sql_service/manifest.py` + 现有 React 文案 + `node --test --experimental-strip-types`

---

## Current context / assumptions

用户可见说明现在叠了三层，同一件事经常说两遍：

1. **字段 `description`**（`SchemaForm` 在 label 下常驻 `.field__desc`）
2. **控件自己**（title、placeholder、select `labels`、开关文案）
3. **面板/对话框脚注**（`.modal__note` / `.dock__note` / `.tip` / `.wh__hint` / `.phe__hint` / `.inputs__where`）

典型冗余：

| 表面 | 现在在说 | 控件已经说了 |
|---|---|---|
| 定时 `mode` description | 「大多数报表选每天就够了」 | 默认就是每天，选项已有「每天」 |
| 定时 `at` + `timezone` | 各说一遍北京时间 | 选项「北京时间（UTC+8）」 |
| Webhook `responseMode` | 等结束节点 / 超时返回 runId | 选项「等待并返回流程结果」「立即返回运行 ID」 |
| SQL `params` description + `phe__hint` | 两处都说留空用同名入参 | 占位符行的 placeholder / tag 已经写「自动取流程入参」 |
| Inspector 备注 description | 「显示在卡片下面，不参与执行…」 | placeholder 已经在教人写什么 |
| Inspector `typeId === 'http.request'` | 「重试在高级设置里」 | HTTP 表单自己有「失败后重试」 |
| 发布对话框 `vpub__hint` | 「留空也能发」 | label 已经标「选填」 |
| 新建流程 `modal__note` | 「选触发器或用模板」 | 两个分组标题一字不差 |
| 失败通知 | 「10 分钟抑制」在 dialog note、字段 desc、流程设置里各讲一遍 | 留一处即可 |
| 消息预览 | 标题「就是会发出去的内容」+ 底下「点运行即真实发送」 | 留底下那句 |

**不是本轮目标（YAGNI）：**

- 不上 `x-ui.help` hover、不抽 i18n、不改 SchemaForm 布局
- 不改节点卡片 `nodeSummary`（那是「配成了什么」，不是说明书）
- 不改校验/运行错误文案（出错才出现）
- 不删代码注释（仓库注释写「为什么」，动的是用户看见的字）
- 不改编 `design/*.html`、不改 README
- 条件警告（未发布 409、配置漂移 401、表格必须 markdown_v2、预览≠运行时刻）留下，只收成一句

**硬约束：**

- 后端 manifest 是正本。改了 `registry.ts` 里 sql/http/wecom/postgres 的 description / labels，必须同步 `server/sql_service/manifest.py`，然后跑 `test/manifestParity.test.ts`
- 禁止新的 `typeId ===` UI 分支；本轮还要删掉 Inspector 里已有的 HTTP 重试特判
- 中文 commit，标题写症状

**文案预算（测试钉死）：**

- 节点 `description`（选择器那行）：`length <= 16`
- 字段 `description`（label 下常驻）：`length <= 28`
- 字段 description 不得包含该字段 `title`（禁止复读标签）
- 常驻脚注：一句，不复述 title / 按钮 / 分组标题

## Task 1: 写下会失败的文案预算测试

**Objective:** 用测试把「说明太长 / 复读标签 / HTTP 重试按 typeId 特判」钉成红灯，后面每改一处都对着它收。

**Files:**
- Create: `test/copyBudget.test.ts`

**Step 1: Write failing test**

```ts
import { test } from 'node:test'
import assert from 'node:assert/strict'
import { readFileSync } from 'node:fs'
import { NODE_TYPES } from '../src/registry.ts'
import type { JsonSchema, NodeType } from '../src/types.ts'

const TYPE_DESC_MAX = 16
const FIELD_DESC_MAX = 28

function fields(t: NodeType): { path: string; title?: string; description: string }[] {
  const out: { path: string; title?: string; description: string }[] = []
  for (const side of ['input', 'output'] as const) {
    const props = (t[side] as JsonSchema | undefined)?.properties ?? {}
    for (const [key, schema] of Object.entries(props)) {
      const description = schema.description
      if (description) out.push({ path: `${t.type}.${side}.${key}`, title: schema.title, description })
    }
  }
  return out
}

test('节点 description 不超过 16 字', () => {
  for (const t of NODE_TYPES) {
    assert.ok(
      t.description.length <= TYPE_DESC_MAX,
      `${t.type} description ${t.description.length} 字：「${t.description}」`,
    )
  }
})

test('字段 description 不超过 28 字，且不复读 title', () => {
  for (const t of NODE_TYPES) {
    for (const f of fields(t)) {
      assert.ok(
        f.description.length <= FIELD_DESC_MAX,
        `${f.path} ${f.description.length} 字：「${f.description}」`,
      )
      if (f.title) {
        assert.ok(
          !f.description.includes(f.title),
          `${f.path} 复读了 title「${f.title}」：${f.description}`,
        )
      }
    }
  }
})

test('Inspector 重试说明不按 typeId 特判', () => {
  const src = readFileSync(new URL('../src/components/Inspector.tsx', import.meta.url), 'utf8')
  assert.equal(
    src.includes("node.data.typeId === 'http.request'"),
    false,
    'HTTP 重试去节点表单自己说，不要在 Inspector 里按 typeId 写一行',
  )
})
```

Run: `node --test --experimental-strip-types test/copyBudget.test.ts`

Expected: FAIL — 多条节点/字段 description 超长；Inspector 仍含 `typeId === 'http.request'`
